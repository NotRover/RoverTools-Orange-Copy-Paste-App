# AGENTS.md

This workspace keeps a single authoritative guide for coding agents: [`CLAUDE.md`](CLAUDE.md).

It covers the layout (three components, three git repos), the client/backend wire
contract, per-repo setup and verification commands, the non-negotiable runtime
invariants, and the doc-ownership rules. Read it before making changes, and treat the
code as the source of truth where a doc and the code disagree.

Component-specific notes live in each component's own `README.md` and `docs/`.
